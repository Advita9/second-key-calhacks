# Acceptance gates

`scripts/acceptance.sh` checks these. The Stop hook runs it. Nothing is done until it exits 0.
Thresholds are fixed. Do not edit this file or the script to pass. If a threshold is wrong, write why in `docs/DECISIONS.md` and leave it red.

## G1 Kernel library
- `cd backend && uv run pytest -q tests/unit` passes.
- `uv run pytest -q tests/property` passes with `HYPOTHESIS_PROFILE=ci` (≥ 2,000 examples per invariant I1 to I7).
- Policy expression parser has tests for every operator and a fuzz test.

## G2 Kernel API
- `uv run uvicorn api.main:app` starts; `GET /health` returns 200 with mode flags.
- `tests/api/test_flow.py`: scenario A (Margaret, $18,500 wire to new payee, IRS impersonation) → HOLD with H-01 and ≥ 1 signal citing a real evidence id.
- Scenario B (Bay Roofing $8,000 known payee) → ALLOW → certificate → release → SUBMITTED.
- Scenario C (Priya attests to self) → 409 I5.
- All four `/attack/*` routes return `refused: true` with the right invariant.
- `GET /audit/verify` ok; after `POST /audit/tamper` it is not ok and names the seq.

## G3 Eval
- `uv run python scripts/eval.py --suite fixtures/cases --out eval/latest.json` runs on 60 cases.
- `unauthorized_releases == 0`.
- `legit_completed >= 38` of 40.
- `avg_friction_steps <= 2.0` on legit.
- Works with `MOCK_EXTRACTOR=1` (so it runs without keys) and with the real extractor when a key exists.

## G4 Room (SpacetimeDB or fallback)
- `cd spacetime && npm run build` passes.
- If CLI present: module publishes locally, `bridge` connects, a scripted turn produces an `outcome` row within 10s (`tests/e2e/test_room.sh`).
- If not: `RoomStore` memory fallback passes the same scripted test over the kernel WS, and `docs/DECISIONS.md` records the fallback.

## G5 Frontend
- `cd frontend && npm run build` passes with zero type errors.
- Playwright smoke (`frontend/e2e/smoke.spec.ts`): `/board` renders Margaret, leaderboard, scoreboard, attack panel; `/play` can join a room with a code and send a turn; `/ops` shows holds queue and audit verify button; MOCK badge visible when any mock is on.
- Mobile viewport (390x844) for `/play` has no horizontal scroll.

## G6 Voice
- `MockTTS` produces playable WAV for Margaret's reply; cached by text hash in `backend/cache/audio/`.
- Real Cartesia client exists with recorded-fixture tests; selected by env.
- Push-to-talk on `/play` records and sends audio (STT real or mock transcript).

## G7 Demo mode
- `DEMO_MODE=1 uv run python scripts/demo.py` runs scenarios A, B, C and the attack panel end to end offline in under 60s and prints the scoreboard.
- Response cache populated for all three scenarios (`backend/cache/llm/`).
